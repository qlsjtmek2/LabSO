# LabSO 빌드 추천 시스템 고도화 계획

> 생성일: 2026-02-03
> 목표: 현재 60~70% 수준의 빌드 추천 정확도를 95% 이상으로 끌어올리기 위한 시스템 고도화
> 핵심 과제: 데이터 정밀도 향상, 시뮬레이터 로직 강화, 실시간 데이터 연동

## 📋 프로젝트 개요

현재 LabSO의 빌드 추천 시스템은 구조적으로는 우수하나, 데이터의 단순화와 하드코딩된 규칙으로 인해 복잡한 챔피언 메커니즘을 반영하지 못하고 있습니다. 이를 해결하기 위해 3단계 고도화 전략을 수립합니다.

---

## 🎯 Phase 1: 챔피언 데이터 및 시뮬레이터 코어 강화 (Foundation)
**목표**: 스킬 메커니즘을 정밀하게 구현하여 데미지 계산의 정확도 확보

- [x] **챔피언 스키마 고도화**
    - [x] `ChampionSchema` 인터페이스에 `mechanics` 필드 추가 (다단 히트, 투사체 속도, 고정 데미지 등)
    - [x] 스킬 로직(`DamageLogic`)에 `returnDamage` (돌아올 때 데미지), `multiHit` (연타) 속성 추가
- [x] **시뮬레이터 엔진 리팩토링**
    - [x] `GenericChampionModel`의 `castSpell` 메서드 개선: 다단 히트 및 투사체 지연 시간 지원
    - [x] `DamageEngine`에 `trueDamage` (고정 데미지) 계산 로직 추가
    - [x] 상태 이상(CC) 연계 데미지 증폭 로직 구현 (예: 아리 매혹 시 데미지 증가)
- [x] **파일럿 챔피언 적용 (Ahri)**
    - [x] `ahri.json` 데이터를 정밀 스키마로 업데이트 (Q 돌아오는 데미지, W/R 다단 히트 명시)
    - [x] 기존 시뮬레이션 vs 신규 시뮬레이션 데미지 비교 테스트 작성

## 🎯 Phase 1.5: 전체 챔피언 데이터 파이프라인 확장 (Mass Production)
**목표**: 160+개 챔피언의 정밀 데이터를 수동 입력 없이 자동화된 파이프라인으로 구축

- [x] **고정밀 데이터 소스 확보**
    - [x] DataDragon의 한계(계수 정보 부실)를 극복하기 위해 `MerakiAnalytics/lolstaticdata` 또는 `CommunityDragon` 원시 데이터 분석
    - [x] 상세 스킬 데이터(계수, 기본 데미지, 쿨다운, 소모값, 스킬 메커니즘 태그) 추출 로직 연구
- [x] **자동 변환기(ChampionDataConverter) 개발**
    - [x] 외부 JSON 포맷 -> LabSO `ChampionSchema` 포맷 변환 스크립트 작성 (`scripts/data-pipeline/convert_champion.ts`)
    - [x] 텍스트 파싱을 통한 특수 메커니즘 태깅 (예: "3번 공격합니다" -> `multiHit: 3` 자동 추출)
- [x] **데이터 검증 및 보정 프로세스**
    - [x] 변환된 데이터의 무결성 검사(Sanity Check) 스크립트 작성 (데미지 0인 스킬 탐지 등)
    - [x] 변환이 까다로운 복합 스킬 챔피언(니달리, 제이스, 아펠리오스 등) 별도 수동 검수 리스트 작성
